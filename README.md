# turtle-planner | 烏龜畫表

> 一個輕量、免安裝的每日任務規劃工具。每天打開就能規劃「今天要完成什麼」，安排任務內容、分類、地點與時間，完成後鎖定規劃並逐項打勾執行。

> 烏龜畫表是一款純前端的單頁應用，使用原生 HTML / CSS / JavaScript 打造，無需任何框架或建置流程，直接用瀏覽器開啟即可使用。所有資料儲存在瀏覽器的 `localStorage`，不會上傳到任何伺服器。

---

## 功能特色

- **每日自動刷新**：以日期作為資料識別，跨日後自動重置為全新的一天（預設建立 3 項空白任務）。
- **任務規劃欄位**：每項任務可填寫「任務內容、任務分類、地點、開始時間、結束時間」。
- **自動計算時長**：輸入起訖時間後，自動計算預計花費時間；若結束時間早於開始時間會即時提示。
- **一鍵完成並鎖定**：完成今日規劃後鎖定所有欄位，避免誤改；鎖定後才可勾選任務完成狀態。
- **空白任務驗證**：鎖定前會檢查是否有未填寫「任務內容」的任務，並以紅框標示、自動捲動至錯誤項目。
- **亮色 / 暗色主題**：可手動切換，並會跟隨系統的 `prefers-color-scheme` 偏好。
- **自訂 Toast 與確認彈窗**：以原生元件取代 `alert` / `confirm`，支援鍵盤操作與焦點管理。
- **響應式設計**：適用手機與桌面螢幕；尊重 `prefers-reduced-motion` 設定。
- **無障礙考量**：彈窗具備 `role="dialog"`、`aria-modal`、焦點鎖定、`Esc` 關閉、Toast 使用 `aria-live`。

## 快速開始

### 方式一：直接開啟

下載或複製本專案後，直接以瀏覽器開啟 `index.html` 即可使用。

> 若使用 `type="module"` 載入腳本，部分瀏覽器在 `file://` 環境下會受 CORS 限制。若遇到此情況，可改用下方的方式二，或將 `<script type="module" src="script.js">` 改為 `<script defer src="script.js"></script>`（本專案未使用 `import/export`，可安全轉換）。

### 方式二：本機靜態伺服器（推薦）

在專案目錄下啟動任一靜態伺服器：

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .
```

再開啟 `http://localhost:8000` 即可。

## 使用說明

1. **規劃任務**：於每張任務卡片填寫內容、選擇分類與地點，並設定開始與結束時間。
2. **新增 / 刪除任務**：點擊「＋ 新增任務」新增；點擊卡片右上角「刪除」移除。
3. **完成今日規劃**：點擊「完成今日規劃」→ 系統驗證 → 確認後鎖定。鎖定後欄位不可再編輯，並可勾選任務表示完成。
4. **切換主題**：點擊右上角圓形按鈕切換亮色 / 暗色。
5. **隔日自動刷新**：隔天再次開啟頁面時，系統偵測到日期變更，會建立全新的空白規劃。

### 資料儲存

- 使用 `localStorage` 儲存，鍵名為 `dailyPlannerData`。
- 主題偏好儲存於 `localStorage` 的 `theme`。
- 清除瀏覽器資料或使用無痕模式將不會保留規劃內容。

## 自訂與擴充

- **任務分類 / 地點選項**：修改 `script.js` 頂部的 `CATEGORIES` 與 `LOCATIONS` 陣列即可。
- **主題色票**：於 `style.css` 的 `:root`（亮色）與 `[data-theme="dark"]`（暗色）中調整 CSS 變數。
- **預設空白任務數量**：調整 `loadData()` 中的迴圈次數（預設 `i < 3`）。

## 瀏覽器支援

支援所有現代瀏覽器（Chrome、Edge、Firefox、Safari 最新版本），需支援 CSS 自訂屬性（CSS Variables）、ES6+ 與 `localStorage`。
